### 🌟 Featured Project

**StayNest — Hostel Management SaaS**
A full-stack platform helping PG and hostel owners manage rooms, residents, rent, and notice periods in one dashboard.

- 🏠 Room & resident management with responsive table/card views
- 💰 Rent tracking with partial payments and a calendar view
- 📋 End-to-end notice period workflow (request → approve/reject → clear)
- 📊 Admin dashboard with a custom animated loader
- 🔌 Evaluating Cashfree for payments and SMS notifications for alerts
