## 🏨 The Build: StayNest

<table>
<tr>
<td width="60%">

A SaaS platform that replaces the WhatsApp-screenshots-and-notebooks way hostel owners run their properties — rooms, residents, rent, and notices, in one place.

<b>What's actually shipped</b>
- 🛏️ Room & resident management — responsive table/card views, member popups
- 💸 Rent tracking with partial payments + a live rent calendar
- 📋 Full notice-period lifecycle: request → approve/reject → clear
- 📊 Admin dashboard, custom-animated hostel loader
- 🔌 Payments (Cashfree) and SMS alerts (Twilio/MSG91) in progress

<b>Where it's headed</b>
Pune & Bangalore hostel owners first — sold founder-led, one conversation at a time.
